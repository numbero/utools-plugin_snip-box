## 1. 一句话定位

在 uTools 里敲几下，把**带占位符的常用文本片段**实时渲染成最终内容，直接粘进你刚才在用的那个应用。

**目标用户**：每天重复输出同类文本的人——开发者（commit 模板、代码骨架、正则、测试数据）、客服/运营（回复话术、通知模板）、任何要反复填同一张表单的人。

**核心差异点**：片段不是死文本。`{{clipboard}}`、`{{date:-1d}}`、`{{uuid}}` 这类占位符在**你浏览和编辑时就实时渲染成真实值**，所见即所粘。

---

## 2. 为什么值得做

| 现状痛点 | 本插件的解法 |
|---|---|
| 系统输入法自定义短语只能存死文本，日期/剪贴板要手动改 | 占位符实时渲染，输出即最终值 |
| 备忘录/记事本存片段，复制前要切窗口、翻找 | uTools 搜索框直接唤起，回车即出 |
| 现有片段工具多为独立 App，脱离 uTools 键盘流 | 原生 uTools 插件，全程不离键盘 |
| 片段一多就找不到 | 分组 + 关键字直达 + 使用频次智能排序 |

**关键可行性结论（已核实官方文档）**：uTools 提供 `utools.hideMainWindowPasteText(text)`、`hideMainWindowTypeString(text)`、`simulateKeyboardTap` 等官方输入 API，因此"隐藏窗口并把内容粘进上一个焦点应用"是**官方能力、零系统权限、跨平台**——不需要自己用 osascript / robotjs 模拟按键。这是本产品成立的前提。

## 3. 名词约定

| 术语 | 含义 |
|---|---|
| **片段 / Snippet** | 一条可复用的文本模板，含名称、内容、关键字、所属分组 |
| **占位符 / Placeholder** | 形如 `{{date}}` 的记号，渲染时替换为真实值 |
| **渲染 / Render** | 把片段内容里的占位符全部替换为当前值，得到**输出文本** |
| **实时预览** | 编辑或浏览片段时，同步展示渲染后的输出文本 |
| **上下文快照** | 进入插件那一刻抓取的剪贴板/当前目录/浏览器 URL/系统信息的**冻结副本** |
| **直达关键字** | 为片段单独注册的 uTools 指令，敲它回车即输出，不显示插件窗口 |
| **输出** | 把渲染结果送到目标位置的动作，分「自动粘贴」与「仅复制」两种 |

## 4. 范围

### 4.1 本次做（按你已确认的选择）

- 片段增删改查、分组管理
- 搜索 + 智能排序（置顶 / 使用频次 / 最近使用）
- **占位符实时渲染预览**（浏览态与编辑态都有）
- 占位符四大类：**剪贴板与日期时间**、**随机与唯一值**、**系统上下文**、**自定义变量（弹框填值）**
- **自动粘贴为默认输出**，修饰键临时改为仅复制
- **单一入口 + 可为片段开启关键字直达**
- 导入导出 JSON 备份
- 深浅色主题（跟随系统 / 强制浅色 / 强制深色），**默认跟随系统**
- **首次空库启动添加 4 条可操作范例**，稳定 ID 防止重复，使用次数从 0 开始；空状态和设置页支持添加范例。筛选标签统计当前搜索匹配的数量，与点击后列表一致。
- **平台范围：只保证 macOS**（你的环境 darwin / arm64）。代码不写平台分支，Windows/Linux 不在验证范围内

### 4.2 本次不做

| 不做 | 原因 |
|---|---|
| 光标定位符（粘贴后光标停在指定位置） | 技术上做不到：粘贴是纯文本投递，无法控制目标应用的光标。任何声称支持的工具都依赖 IDE 插件 |
| 拼音首字母搜索 | 需引入拼音库（体积大）。改为「每个片段可写英文关键字」达到同等效果，且更可控 |
| 富文本 / 图片 / 文件片段 | MVP 只做纯文本。图片可走 `hideMainWindowPasteImage`，列为 P2 |
| 逐片段加密（私密片段） | 见 §11 风险 R4，MVP 只在文档与 UI 上明确告知云同步风险 |
| 多设备同步冲突合并界面 | `utools.db` 自带云同步，冲突由 uTools 处理，插件不介入 |
| 云端片段库 / 外部服务 | 官方禁止插件请求外部资源（[FAQ](https://www.u-tools.cn/docs/developer/faq.html)），全部本地 |

## 5. 核心用户旅程

### 旅程 A：高频输出（3 秒完成）

```
在 VSCode 写代码 → 需要一段带今天日期的 commit 模板
  ↓ 按 uTools 唤起键
  ↓ 敲「commit」
  ↓ 列表第一项就是它，右侧已显示渲染结果：
      feat(parser): 支持日期偏移  # 2026-09-06
  ↓ 回车
  ↓ 窗口隐藏，内容已粘进 VSCode，光标就在末尾
```

### 旅程 B：直达关键字（2 秒完成，不显窗）

```
在微信里要发邮箱签名
  ↓ 唤起 uTools，敲 sign（该片段已开启直达）
  ↓ 回车 —— 插件窗口根本不出现
  ↓ 内容已粘进微信输入框
```
> 实现：`setFeature({ code, cmds:['sign'], mainHide: true })`，`onPluginEnter` 收到 code 后直接渲染输出。

### 旅程 C：新建片段（所见即所得）

```
  ↓ 主指令进入插件 → 点「新建」
  ↓ 左侧写模板：  你好，今天是 {{date}}，工单 {{?编号}} 已处理
  ↓ 右侧实时渲染：你好，今天是 2026-09-06，工单 {{?编号}} 已处理
                   └ 未识别占位符红色高亮 + 悬浮提示「未知占位符」
  ↓ 点右侧「可用占位符」→ 分类清单 → 点击即插入到光标处
  ↓ 填名称、选分组、（可选）设直达关键字 → 保存
```

### 旅程 D：临时只要复制，不想粘

```
  ↓ 选中片段，按 Option+Enter（macOS）/ Alt+Enter（Win/Linux）
  ↓ 仅复制到剪贴板并退出，焦点回到原应用，你自己决定粘到哪
```

## 7. 占位符规格

### 7.1 语法

```
{{ 名称 }}                  最简形式
{{ 名称:参数 }}              单参数
{{ 名称:参数1|参数2 }}        多参数（竖线分隔）
{{ ?变量名 }}                待填变量，输出时弹表单询问（见 7.6）
{{ ?变量名=默认值 }}          待填变量，带默认值
\{{ 名称 }}                 转义，输出字面量 {{ 名称 }}
```

- 名称大小写**不敏感**（`{{DATE}}` = `{{date}}`）；参数大小写敏感（日期格式串 `YYYY` ≠ `yyyy`）
- 允许内部空格：`{{ date : -1d }}` 等价于 `{{date:-1d}}`
- **不支持嵌套**：`{{date:{{fmt}}}}` 视为非法，走 FR-44 降级
- 未识别名称 → 原样保留 + 标红（FR-43）

### 7.2 剪贴板

| 占位符 | 输出 | 说明 |
|---|---|---|
| `{{clipboard}}` | 当前剪贴板文本 | 取**上下文快照**中的值（FR-45） |
| `{{clipboard:n}}` | 前 n 个字符 | `{{clipboard:20}}` |
| `{{clipboard:line:n}}` | 第 n 行（1 起） | 超出范围输出空串 |
| `{{clipboard:trim}}` | 去首尾空白 | |
| `{{clipboard:upper}}` / `{{clipboard:lower}}` | 全大写 / 全小写 | |

> 剪贴板**读取**没有官方 utools API（官方只有 `copyText/copyImage/copyFile` 写侧），因此走 preload 的 Electron `clipboard.readText()`，经 `window.api.readClipboard()` 桥接。
>
> **为什么必须快照冻结**：`hideMainWindowPasteText` 内部很可能经剪贴板投递。若不冻结，输出一次后 `{{clipboard}}` 会变成刚输出的片段自身，第二次渲染结果就错了。快照从根上消除这个自污染。
>
> 快照抓取失败或剪贴板为空 → 渲染为空串，预览中标灰提示「剪贴板为空」。

### 7.3 日期时间

**基础**

| 占位符 | 示例输出 |
|---|---|
| `{{date}}` | `2026-09-06` |
| `{{time}}` | `22:15:03` |
| `{{datetime}}` | `2026-09-06 22:15:03` |
| `{{iso}}` | `2026-09-06T22:15:03.123Z` |
| `{{timestamp}}` | `1788888903`（秒） |
| `{{timestamp_ms}}` | `1788888903123`（毫秒） |
| `{{year}}` / `{{month}}` / `{{day}}` | `2026` / `09` / `06`（月日补零） |
| `{{hour}}` / `{{minute}}` / `{{second}}` | `22` / `15` / `03` |
| `{{weekday}}` | `星期日` |
| `{{weekday:short}}` | `周日` |
| `{{weekday:en}}` | `Sunday` |
| `{{weekday:num}}` | `0`（0=周日） |

**自定义格式** `{{date:FORMAT}}`

| 记号 | 含义 | 记号 | 含义 |
|---|---|---|---|
| `YYYY` | 4 位年 | `HH` | 24 时制时（00-23） |
| `YY` | 2 位年 | `hh` | 12 时制时（01-12） |
| `MM` | 月（01-12） | `mm` | 分（00-59） |
| `M` | 月（1-12） | `ss` | 秒（00-59） |
| `DD` / `D` | 日（补零 / 不补） | `A` / `a` | `AM/PM` / `am/pm` |
| `dddd` | `星期日` | `SSS` | 毫秒 |
| `ddd` | `周日` | `X` | Unix 秒 |
| `MM月DD日` 等中文字符 | 原样保留 | `x` | Unix 毫秒 |

示例：`{{datetime:YYYY年MM月DD日 HH:mm}}` → `2026年09月06日 22:15`

> 格式串中若要输出**字面量 ASCII 字母**，用方括号包裹：`{{date:YYYY[AD]}}` → `2026AD`。中文等非 ASCII 字符不是记号，无需转义，直接写即可（`YYYY年` 就能正常输出）。
>
> **防呆**：若格式串里含 ASCII 字母却一个记号都没命中（如 `{{date:zzz}}`），判为参数非法并标黄提示，避免用户拼错格式后拿到一串字面量却不知所以然。

**偏移** `{{date:OFFSET}}`

| 单位 | 含义 | 单位 | 含义 |
|---|---|---|---|
| `y` | 年 | `h` | 小时 |
| `M` | 月 | `m` | 分钟 |
| `w` | 周 | `s` | 秒 |
| `d` | 天 | | |

- 语法：`正负号 + 数字 + 单位`，如 `-1d`（昨天）、`+2h`、`-30m`、`+1M`（下月）
- 特殊值：`startOfDay` / `endOfDay` / `startOfWeek` / `endOfWeek` / `startOfMonth` / `endOfMonth`，写法 `{{date:@startOfWeek}}`

**偏移 + 格式组合**：冒号后第一段智能识别（含 `+`/`-` 或以 `@` 开头 → 偏移；否则 → 格式），第二段（`|` 后）必为格式。

| 写法 | 含义 |
|---|---|
| `{{date:-1d}}` | 昨天，默认格式 |
| `{{date:YYYY/MM/DD}}` | 今天，自定义格式 |
| `{{date:-1d\|YYYY/MM/DD}}` | 昨天，自定义格式 |
| `{{datetime:+2h\|HH:mm}}` | 2 小时后，只输出时分 |
| `{{date:@startOfMonth}}` | 本月 1 日 |

**便捷别名**

| 占位符 | 等价于 |
|---|---|
| `{{today}}` | `{{date}}` |
| `{{yesterday}}` | `{{date:-1d}}` |
| `{{tomorrow}}` | `{{date:+1d}}` |
| `{{now}}` | `{{datetime}}` |

### 7.4 随机与唯一值

| 占位符 | 示例输出 | 说明 |
|---|---|---|
| `{{uuid}}` | `3f2b8c1e-4a7d-4f1b-9c2e-8d5a1f0e3b7c` | RFC4122 v4 |
| `{{uuid:upper}}` | `3F2B8C1E-...` | 大写 |
| `{{uuid:short}}` | `3f2b8c1e4a7d4f1b` | 去连字符取前 16 位 |
| `{{nanoid}}` | `V1StGXR8_Z5jdHi6` | 默认 16 位，字母表 `A-Za-z0-9_-` |
| `{{nanoid:8}}` | `xK3_pLm9` | 指定长度 1-128 |
| `{{random:1-100}}` | `42` | 闭区间整数 |
| `{{random:6}}` | `839201` | 单个数字 = 生成 n 位随机数字串（首位可为 0） |
| `{{pick:红\|绿\|蓝}}` | `绿` | 随机取一项 |
| `{{shuffle:a,b,c}}` | `c,a,b` | 打乱顺序，逗号分隔 |

> **每次渲染值都不同**——包括预览。因此编辑态预览里随机类占位符每次按键都会变，这是预期行为；UI 上会给这类占位符加一个小标记提示「每次输出都不同」，避免用户误以为预览就是最终值。
>
> `crypto.randomUUID` 在本插件的渲染层版本（Chromium ~91）不可用（见 §10 语法红线），改用 `window.crypto.getRandomValues` 手写 v4 UUID；nanoid 同样手写。

### 7.5 系统上下文

| 占位符 | 示例输出 | 来源 |
|---|---|---|
| `{{user}}` | `numbero` | preload `os.userInfo().username` |
| `{{home}}` | `/Users/numbero` | preload `os.homedir()` |
| `{{hostname}}` | `MacBook-Pro.local` | preload `os.hostname()` |
| `{{platform}}` | `macOS` | 友好名（`isMacOS/isWindows/isLinux`） |
| `{{os}}` | `darwin` | 原始 `process.platform` |
| `{{arch}}` | `arm64` | preload `os.arch()` |
| `{{tmpdir}}` | `/var/folders/...` | preload `os.tmpdir()` |
| `{{cwd}}` | `/Users/numbero/Documents/Workspace/ui-design` | preload `process.cwd()` |
| `{{folder}}` | 当前访达/资源管理器目录 | `utools.readCurrentFolderPath()`（异步，快照期抓取） |
| `{{url}}` | 当前浏览器标签页 URL | `utools.readCurrentBrowserUrl()`（异步，快照期抓取） |
| `{{url:title}}` | 标签页标题 | 同上返回值中的 title |
| `{{appVersion}}` | `5.2.0` | `utools.getAppVersion()` |
| `{{pluginVersion}}` | `1.0.0` | plugin.json 版本 |

> `{{folder}}` / `{{url}}` 依赖调用插件时的宿主上下文，**可能返回 null**（比如当前焦点应用不是访达/浏览器）。此时渲染为空串，预览中标灰提示「无可用上下文」。这与剪贴板一样，必须在快照期一次性抓取——`readCurrentBrowserUrl` 读的是"唤起 uTools 那一刻"的浏览器状态，插件窗口打开后再读就拿不到了。

### 7.6 自定义变量

| 写法 | 含义 |
|---|---|
| `{{?姓名}}` | 待填变量，无默认值 |
| `{{?姓名=张三}}` | 待填变量，默认值 `张三` |
| `{{?工单号=T-}}` | 默认值可以是部分前缀，方便用户接着打 |

**渲染行为**：这类占位符**不在渲染阶段替换**，而是被收集为「待填变量」列表，触发 FR-71 的填值表单；用户提交后才做最终替换。

**完整示例**

```
模板：  {{date}} 工单 {{?工单号}} 反馈：{{?问题描述=用户反馈}}
        处理人 {{user}}，已修复并提交 {{?commit_id}}

命中后弹出表单（3 个字段，按模板中首次出现顺序排列）：
        工单号     [________]
        问题描述   [用户反馈_]   ← 预填默认值
        commit_id  [________]

填值后实时预览：
        2026-09-06 工单 T-1024 反馈：登录页 500
        处理人 numbero，已修复并提交 a1b2c3d

回车 → 自动粘贴到上一个应用
```

**规则细节**

- 变量名规则见 FR-75：允许中文/字母/数字/下划线，禁止空格与 `=` `{` `}`
- 同名变量去重，表单里只出现一次，替换时全量替换（FR-75）
- 字段顺序 = 在模板中**首次出现**的顺序
- 变量值不做递归解析（FR-78）
- 默认值里若含 `|` 或 `}`，按第一个 `}` 截断，不做转义（保持语法简单）

### 7.7 渲染引擎行为约定

| 场景 | 行为 |
|---|---|
| 未知占位符名 | 原样保留 + 标红（FR-43） |
| 参数非法 | 原样保留 + 标黄 + 提示原因（FR-44） |
| 上下文缺失（剪贴板空 / folder 为 null） | 替换为空串 + 标灰提示 |
| 定界符不成对（`{{date`） | 视为普通文本，原样输出 |
| 含 `{{?变量}}` | 不替换，收集为待填变量 → 触发填值表单（FR-70~79） |
| 待填变量在编辑态预览中 | 显示为蓝色高亮胶囊 `{{?姓名}}`，不显示为值（FR-79） |
| 渲染抛任何异常 | 捕获，降级为原样输出，绝不打断 UI（FR-44） |
| 渲染耗时 | 单片段 < 1ms；预览整体重渲染 < 16ms（不掉帧） |

## 8. 关键设计决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | **上下文快照 + 冻结**，渲染只读快照 | 三重收益：① 渲染变纯同步函数，预览零延迟；② 规避 `hideMainWindowPasteText` 污染剪贴板导致的自反馈；③ `readCurrentBrowserUrl` 只在唤起瞬间可读，必须那时抓 |
| D2 | 自动粘贴用官方 `hideMainWindowPasteText`，不自己模拟按键 | 官方 API、零权限、跨平台。自己 osascript/robotjs 要辅助功能权限且平台分裂 |
| D3 | 另备 `hideMainWindowTypeString` 逐字输入模式 | 部分应用（某些终端、虚拟机窗口、Windows 下以管理员身份运行的程序）拒绝合成粘贴事件；逐字输入兼容这些场景且支持 Emoji |
| D4 | 不做拼音搜索，改为片段可填英文关键字 | 省掉一个体积可观的依赖；关键字同时服务于搜索与直达，一举两得 |
| D5 | 占位符语法用 `{{ }}` 且**定界符可全局切换** | `{{ }}` 最通用，但用户的片段本身可能就是 Vue/Handlebars 模板，会撞车。可切换定界符 + `\{{` 转义两条退路 |
| D6 | 日期格式串自己实现，不引 dayjs | 只需 §7.3 那张表的 token，手写 <100 行；引库要本地 vendor（外部 CDN 被官方禁止），不划算 |
| D7 | 分层：页面层独占 utools API 与持久化，preload 只做系统 I/O | 页面层可在普通浏览器里用内存 shim 预览（阶段二的高保真稿直接复用），preload 可脱离 uTools 单测 |
| D8 | 关键字直达用动态 `setFeature`，删除时强制 `removeFeature` | 残留幽灵指令会污染 uTools 全局指令空间，是最容易被用户感知为"插件有 bug"的问题 |

## 9. 非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 冷启动到列表可交互 < 300ms；500 片段规模下搜索输入无卡顿（防抖 80ms）；单次渲染 < 1ms |
| **规模上限** | 设计目标 500 片段；超过 1000 时给出性能提示但不禁用 |
| **平台** | **只保证 macOS**（darwin / arm64）。不写平台分支代码。`{{platform}}`/`{{os}}` 占位符仍返回真实值，只是不做 Windows/Linux 专项适配与验证 |
| **布局** | **流式布局，不写死像素宽度**。官方未文档化 uTools 主窗口宽度（只文档化了 `pluginSetting.height`，默认 544，最小 1），因此 UI 必须自适应任意宽度；高保真稿按 680px 展示并提供宽度切换开关供比对 |
| **主题** | 跟随系统 / 强制浅色 / 强制深色 三态，**默认跟随系统**；`data-theme` 属性 + CSS 变量令牌；「跟随」时监听 `matchMedia('(prefers-color-scheme: dark)')` |
| **图标** | `plugin.json.logo` 用 **PNG，≤256×256**（发布校验硬性要求，SVG 不被 logo 字段接受）；`features[].icon` 用 SVG，内嵌 `@media (prefers-color-scheme: dark)` 做深浅色自适应（官方无双图标字段） |
| **应用内图标** | 全部内联 SVG + `currentColor`，跟随任意主题切换 |
| **数据** | 片段/分组存 `utools.db`（云同步）；设置存 `utools.dbStorage`；无外部网络请求 |
| **容错** | preload 加载失败、`window.utools` 未就绪、渲染异常——均不得导致白屏；错误集中记录并可一键复制（FR-65） |
| **可访问性** | 全键盘可操作（FR-26）；焦点可见；正文对比度 ≥ 4.5:1 |

## 10. 技术架构

### 10.1 分层

```
┌─ 页面层 (index.html + js/)  ─────────────────────────┐
│  UI 渲染 · 搜索排序 · 模板引擎 · utools API · db 持久化 │
│  不 require 任何 Node 模块，不发外部网络请求            │
└──────────────────┬──────────────────────────────────┘
                   │ window.api.* （全部返回 Promise）
┌──────────────────┴──────────────────────────────────┐
│  preload.js — 只做系统 I/O                            │
│  clipboard.readText · os.userInfo/homedir/hostname/  │
│  arch/tmpdir · fs 读写（导入导出）                     │
└─────────────────────────────────────────────────────┘
```

### 10.2 模块划分（阶段三落地）

```
plugin.json          main / logo / preload / features / pluginSetting
index.html           单一页面，双视图（列表 / 编辑器）
preload.js           系统 I/O 桥接，暴露 window.api
js/
  bootstrap.js       延迟引导：轮询等 window.utools 就绪再启动
  utools-proxy.js    惰性代理 new Proxy({}, {get:(_,k)=>window.utools[k]})
  context.js         上下文快照抓取与冻结
  template.js        占位符解析 + 渲染引擎（纯函数，可独立验证）
  store.js           db 读写、导入导出、分组/片段 CRUD
  features.js        直达关键字注册与清理
  search.js          过滤 + 相关度/智能分排序
  ui-list.js         列表视图
  ui-editor.js       编辑器 + 实时预览
  ui-settings.js     设置页
  theme.js           三态主题
styles/              CSS 变量令牌 + 双主题
assets/              logo.png、feature icons
build.sh             拷贝运行必需文件到 dist/，剔除 .DS_Store
```

### 10.3 必须遵守的环境红线

渲染层约 **Chromium 91**、preload 约 **Node 14/16**（以开发时官方文档表述为准）。

**禁用**：`structuredClone`、`crypto.randomUUID`、`String.replaceAll`、`Array.at`、逻辑赋值 `??=` `||=` `&&=`、页面层 ES module（`<script type="module">`）、任何外部网络请求与外部 JS 动态加载。
**可用**：可选链 `?.`、空值合并 `??`、`async/await`、`Proxy`、`window.crypto.getRandomValues`、CSS 变量、`matchMedia`。

**已知坑（来自真实项目经验，官方文档不写）**：

1. **渲染进程定时器没有 `unref`**——preload 里 `setInterval(...)` 返回 number，链式 `.unref()` 直接 TypeError 且 **preload 静默崩溃**：页面照常渲染但所有系统能力全假。任何 `.unref()` 调用前先 `typeof x.unref === 'function'` 守护。排查入口：插件窗口 DevTools Console 的 `Unable to load preload script`。
2. **`window.utools` 注入可能晚于页面脚本解析**——绝不在解析期判定"有无 utools"然后装兜底模拟（静默 fallback 是最坏容错：UI 正常但数据库零痕迹）。用延迟引导 + 惰性代理。
3. **preload 变更不热更新**——页面改动可 DevTools 重载，preload 改动必须重新进入插件或重启 uTools。

### 10.4 验证策略

遵循你的既定偏好：**不搭自动化测试基建**，直接交付可用正式版。

- 模板引擎（纯函数）用一次性 Node 冒烟脚本核对 §7 全部占位符，跑完删除，不留测试目录
- 页面层用浏览器 + 内存 shim 跑交互（阶段二的高保真稿就是这个 shim 的雏形，可直接复用）
- 真实集成在 uTools 内冷启动验证；交付时**如实区分**「已实测跑通」与「只过了语法/构建、从未真实运行」的部分
- 插件内置「一键复制诊断信息」（FR-65），把问题反馈成本压到一次粘贴

## 11. 风险与对策

| ID | 风险 | 影响 | 对策 |
|---|---|---|---|
| R1 | `hideMainWindowPasteText` 在 macOS 某些应用失效（Terminal/iTerm 的部分模式、虚拟机窗口如 Parallels/VMware、以安全输入模式运行的密码框、部分 Electron 应用） | 用户以为插件坏了 | FR-34 提供逐字输入模式；FR-36 失败时先保证内容进剪贴板 + 通知告知手动粘贴 |

| R7 | logo 格式不合规导致无法发布 | 发布卡住 | logo 用 PNG ≤256×256；SVG→PNG 用浏览器 canvas `drawImage` + `toDataURL('image/png')` 栅格化 |

## 12. 验收标准

阶段三交付时，以下每条都必须能在 uTools 里真实操作通过：

1. 新建片段 `你好 {{user}}，今天 {{date}}`，保存后列表项预览显示 `你好 numbero，今天 2026-09-06`——占位符已是真实值
2. 回车后 uTools 窗口隐藏，内容出现在**唤起前**那个应用的输入位置
3. `Option+Enter` 只复制不粘贴，剪贴板内容正确
4. 新建片段含 `{{clipboard}}`，复制一段文字后唤起插件，预览显示该文字；输出一次后**再次**渲染，`{{clipboard}}` 仍是原文字而非刚输出的内容（验证 R3）
5. `{{date:-1d|YYYY年MM月DD日}}` 渲染为昨天的中文日期
6. `{{uuid}}` 连续两次输出值不同
7. `{{url}}` 在浏览器标签页唤起插件时有值，在非浏览器应用唤起时预览标灰提示而非报错
8. 未识别的 `{{foobar}}` 预览中标红，保存不被阻断，输出时原样保留
9. 输入 `{{date` （不成对）当普通文本输出，不崩溃
10. 500 条片段规模下，搜索输入无可感知延迟
11. 为片段开启直达关键字 `sign`，在 uTools 搜索框敲 `sign` 回车，**窗口不出现**且内容已粘出
12. 删除该片段后，`sign` 指令从 uTools 消失（验证 R5）
13. 导出 JSON → 清空数据 → 导入 JSON，片段与分组完整恢复
14. 切换主题三态（跟随/浅/深），界面无残留错色，图标随主题变化
15. 全键盘走完「搜索 → 选中 → 输出」与「新建 → 填写 → 保存」两条路径，不碰鼠标
16. DevTools Console 无 `Unable to load preload script`，无未捕获异常
17. 新建片段 `{{date}} 工单 {{?工单号}} 已处理，联系人 {{?姓名=张三}}`，回车后弹出填值表单：2 个字段、顺序为工单号→姓名、姓名格已预填 `张三`
18. 在表单里打字时，下方预览区**同步**变化；`Cmd+Enter` 输出，内容粘进上一个应用且日期为今天
19. 模板里同一个 `{{?工单号}}` 写两遍，表单里**只出现一个**工单号字段，填值后两处同时替换
20. 变量值填入字面量 `{{date}}`，输出结果就是 `{{date}}` 六个字符，**不**被二次渲染成日期（验证 FR-78）
21. 给一个含 `{{?变量}}` 的片段开启直达关键字，插件提示会降级为显窗模式；敲该关键字回车后**窗口出现**并直接弹出填值表单，而不是静默输出带 `{{?变量}}` 的原文（验证 FR-77）
